# Version Policy

Default branch: `main`.

After bootstrap, direct modification of `main` is prohibited except when explicitly authorized by a CONTROL foundation task.

Future branch examples:

- `task/<TASK-ID>`
- `fix/<TASK-ID>`
- `feature/<TASK-ID>`

Commit examples:

- `[MT5-012A] ...`
- `[FIX] ...`
- `[HEALTH] ...`
- `[DOC] ...`

Do not mix unrelated changes in one commit.
Maintain TASK ID -> Branch -> Commit -> Report traceability.
