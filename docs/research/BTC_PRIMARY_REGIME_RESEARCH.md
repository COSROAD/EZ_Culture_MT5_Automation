# BTC Primary Regime Research

BTC is the primary trading/research target while the existing five-market architecture remains intact.

Hierarchy: `LONG-HORIZON REGIME -> MEDIUM-HORIZON SETUP -> SHORT-HORIZON TIMING`.

- M30/H1: primary regime/trend confirmation
- M5: setup
- M1: entry/add/exit timing
- Tick: microstructure/shock/timing

Tactical pullbacks/rebounds do not automatically flip long-horizon regime. BTC uses dynamic NQ relative strength, rates/dollar context, risk/liquidity/credit/oil, crypto-specific liquidity, ETF/institutional flows, regulation and geopolitics where current data exists. Missing macro data remains `VERIFY_REQUIRED`.

Stablecoin/T-bill connectivity is a structural hypothesis only, never automatic BUY authority. Regime direction, entry permission, add permission and exit state remain separate. Historical similarity is not entry authority. No permanent bullish hard-code is permitted. Research/shadow only.
