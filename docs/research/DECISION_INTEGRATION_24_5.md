# 24/5 End-to-End Decision Integration

Subsystem PASS does not equal Decision System PASS.

Chain:
LIVE DATA → FRESHNESS → UTC TIME ALIGNMENT → FEATURE EXTRACTION → CROSS-MARKET REGIME → HISTORICAL MATCH → CURRENT CONFIRMATION → M1 TIMING → M5 CONFIRMATION → MT5 SIGNAL CONTEXT → RISK/ADD GATE → SHADOW DECISION → OUTCOME FEEDBACK.

10M and 1H are reporting/research clocks only, never execution clocks. Historical similarity alone cannot authorize BUY/SELL. Every decision must preserve source freshness, conflict, risk permissions, and an explainable trace. No live order path is present in this phase.
