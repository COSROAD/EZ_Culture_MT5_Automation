# BTC Historical Sample Expansion

This phase expands BTC/NQ historical research using actual available data only. Overlapping observations from the same move are clustered with `EVENT_CLUSTER_ID`; primary statistics use independent representatives only.

Research separates healthy/failed long-regime pullbacks, bearish continuation/rebound cases, false bullish/bearish reversals and BTC/NQ decoupling. ADD/NO_ADD/EXIT candidate classifications use event-time or earlier inputs only. Future prices are reserved for outcome evaluation such as MFE, MAE, follow-through, protection rate and opportunity cost.

M30/H1 remains regime authority, M5 setup, M1 timing, Tick microstructure. Macro minute inputs remain `VERIFY_REQUIRED`; ETF/stablecoin/institutional flows remain `VERIFY_REQUIRED`; regulatory state remains `REFERENCE_ONLY_OR_VERIFY_REQUIRED`. No production thresholds and no live-order path are created.
